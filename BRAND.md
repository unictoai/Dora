# Dora Brand System

Dora uses a quiet, privacy-first visual identity built around a rounded speech-bubble `D` mark. The symbol communicates local conversation without relying on a literal wordmark, so it remains legible in an Android launcher, a 24dp navigation icon, a first-run screen, and a GitHub release image.

## Primary asset

`app/src/main/res/drawable-nodpi/dora_logo.png` is the primary generated mark. It is used by the Android launcher and first-run onboarding. Keep the symbol clear of extra text or small decorative detail when exporting future densities.

## Palette

| Role | Value | Use |
|---|---|---|
| Dora indigo | `#312E81` | Primary controls, deep brand field, focus states |
| Dora violet | `#4C1D95` | Secondary gradient tone and dark-mode accent |
| Dora lavender | `#EEF2FF` | Soft brand-tinted surfaces |
| Dora ink | `#111827` | Primary light-mode text |
| Dora cloud | `#F8FAFC` | Light-mode background |
| Dora signal | `#FF9F5B` | Small warmth accent; use sparingly |

## Usage rules

The mark should appear with generous padding and a simple surface. Do not add competing badges, gradients behind the mark, or dense dashboard decoration. The product UI should keep the brand mark quiet: the primary focus is the user’s model and conversation.
